# ベトナムの川底で…

バカバカしいお題について AI と口喧嘩する、ディベート格闘ゲーム（スマホ向け PWA）。

## 遊び方
1. お題を決める（ランダム／自分で入力／AIに出させる）
2. 賛成か反対かを選ぶ。AI は逆側につく
3. 対戦相手の性格を選ぶ（理屈屋・煽り屋・説教おばあちゃん・熱血コーチ）
4. 交互に言い合う。発言ごとに AI 審判が「論理・勢い・笑い」で採点し、相手の HP を削る
5. HP が 0 になったら「論破！」。10 ターンで決着しなければ HP 判定
6. 戦績（勝敗・最大ダメージ・名言）は端末内に保存

## AI について
- Gemini API（無料枠）を使います。**設定画面で自分の API キーを入力**してください（[Google AI Studio](https://aistudio.google.com/apikey) で発行）。
- キーはブラウザの localStorage にのみ保存され、Google の API にしか送られません（サーバーなしの静的サイトです）。
- キー未設定でも「練習モード」（定型文で反論・簡易採点）で遊べます。
- 反論役と審判役は別プロンプト。審判は JSON（`logic` / `momentum` / `humor` / `damage` / `critical` / `comment`）を返します。

## 構成
素の HTML / CSS / JS。ビルド不要。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（タイトル・準備・バトル・結果・戦績・設定） |
| `app.js` | ゲーム進行・戦績・設定 |
| `ai.js` | Gemini 呼び出し、反論／審判／お題生成プロンプト、AI の性格、練習モード |
| `topics.js` | ランダムお題 |
| `sw.js` / `manifest.json` | PWA（オフラインでアプリ本体が開ける・ホーム画面追加） |
| `icons/` | アイコン（SVG 原本と PNG 書き出し。`maskable` は角丸なし版） |

## 公開（GitHub Pages）
Settings → Pages → Source を「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` に設定。
ファイルを更新したら `sw.js` の `CACHE` の版数を上げると、端末側のキャッシュが更新されます。
